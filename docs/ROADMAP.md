## 阶段 0 的"首次出包"缺口

本仓库在无显示环境的云机器上开发，Unity Editor 需要许可激活才能跑批处理构建。
两条路径任选：

1. **本机出包**：装 Unity 6000.0.76f1+（含 Windows Build Support），跑
   `tools/build_windows.sh`（或 .ps1）。脚本、构建入口（`Lingyan.EditorTools.BuildScript.BuildWindows`）
   与场景表都已就绪。
2. **云端/CI 出包**：在 Cursor Dashboard（Cloud Agents → Secrets）配置
   `UNITY_LICENSE`（.ulf 文件内容）或 `UNITY_EMAIL` + `UNITY_PASSWORD`（个人版），
   后续代理运行即可装编辑器并出包验证。
